Auto Header

20-Row Heuristic Header Detection

Automatically skips export banners and title rows across the first 20 rows of a CSV/TSV or clipboard paste to locate the real header row.

Smart Mapping

NFD Normalization & 80%-Pass Matching

Normalizes headers (accents, *, (required)) and suggests unmapped columns only when ≥80% of sample values pass type parsing and validation rules.

Reconciliation

Unknown Value Questions & Upsert

Surfaces unknown select values as explicit mapping questions and resolves intra-file duplicates or updates against existing database records.

Batch Retry

Batch Submit & Retry Rejected Rows

Submits validated rows in configurable batches and isolates server-rejected rows for inline correction and targeted retry.

Lux.Spreadsheet.Core · Headless SpreadsheetImporterCore · NativeAOT
using Blux.UI.Tools;

var schema = new SpreadsheetSchema
{
    Key = "rates",
    Columns =
    [
        new SpreadsheetColumnSchema { Key = "code", Label = "Code", Required = true },
        new SpreadsheetColumnSchema { Key = "price", Label = "Unit Price", Kind = SpreadsheetColumnKind.Number, DecimalSeparator = ',', Rules = [SpreadsheetRule.Min(0)] },
        new SpreadsheetColumnSchema { Key = "currency", Label = "Currency", Kind = SpreadsheetColumnKind.Select, Options = [new("EUR", "Euro", ["€", "EUR"]), new("USD", "US Dollar", ["$", "USD"])] }
    ]
};

var importer = new SpreadsheetImporter(schema);
importer.LoadText(csvText, "rates.csv"); // Auto-detects header row & 80%-pass suggestions
