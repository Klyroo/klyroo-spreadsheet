# Klyroo.Spreadsheet Skill

- Use `Klyroo.Spreadsheet.Core` (`SpreadsheetSchema`, `SpreadsheetImporter`) for deterministic CSV/TSV/clipboard import pipelines in C#.
- Use `Klyroo.Spreadsheet` (`AddKlyrooSpreadsheet()`, `KlySpreadsheetImport`) for interactive wizard or single-page spreadsheet import flows.
