# Lux.Spreadsheet (LuxStack)

Headless Spreadsheet Import Engine & Multi-Step Wizard for .NET, Blazor, and .NET MAUI:
- **`Lux.Spreadsheet.Core`**: 100% Headless C# `SpreadsheetImporter` and `SpreadsheetSchema` (CSV/TSV/clipboard parsing, 20-row header layout detection, NFD header normalization, 80%-pass column suggestions, unknown value resolution, duplicate & existing record policies, inline cell edits, batch submit & server rejection retry).
- **`Lux.Spreadsheet`**: Blazor & MAUI Hybrid `BxSpreadsheetImport` wizard and review table component (`AddLuxSpreadsheet()`).
